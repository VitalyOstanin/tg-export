## Конвенции

- Имя файла: `NNNN-краткое-название.md` с возрастающим номером.
- Каждая запись содержит контекст, рассмотренные варианты, принятое решение и его последствия.
- Принятые записи не переписываются: при изменении решения добавляется новая запись со ссылкой на предыдущую.
- Неизменяемо тело записи: контекст, варианты, решение и последствия. Поле статуса обновляется по
  ходу жизни решения (`принято` → `заменено ADR-NNNN` либо `устарело`).
- Записывается решение, которое дорого пересматривать: выбор механизма, раскладка данных на диске,
  порядок необратимых шагов. Правка, которую видно из кода и которая откатывается одним коммитом,
  ADR не требует.
