# Architecture Decision Records (ADR)

В этом каталоге фиксируются значимые архитектурные решения проекта в формате
[MADR](https://adr.github.io/madr/).

## Содержание

- [0001 — Использование ADR](0001-use-adr.md)

## Конвенции

- Имя файла: `NNNN-краткое-название.md` с возрастающим номером.
- Каждая запись содержит контекст, рассмотренные варианты, принятое решение и его последствия.
- Принятые записи не переписываются: при изменении решения добавляется новая запись со ссылкой на предыдущую (статус `superseded by`).
