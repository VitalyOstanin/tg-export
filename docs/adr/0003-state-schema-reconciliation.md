# 0003 — Сверка схемы базы состояния с DDL вместо миграций

- Статус: принято
- Дата: 2026-08-22

## Контекст

Состояние экспорта хранится в SQLite рядом с выгрузкой (`.tg-export-state.db`). Схема
объявлена одним скриптом `SCHEMA_SQL` и применяется при открытии через `CREATE TABLE IF NOT
EXISTS`.

Такой скрипт ничего не делает с уже существующим файлом. Колонка, добавленная в схему новой
версией, не появлялась в базах на диске, и экспорт падал на первой же записи в середине прогона:
`table catalog_cache has no column named is_archived`.

## Рассмотренные варианты

1. Полноценный механизм миграций (alembic, umzug и аналоги): нумерованные шаги, таблица
   применённых версий.
2. Собственный список миграций в коде, привязанный к `PRAGMA user_version`.
3. Сверка фактических колонок с объявленными в том же DDL и добавление недостающих при открытии.

## Решение

Принят вариант 3. При открытии базы фактический состав колонок (`PRAGMA table_info`) сверяется
с ожидаемым, а ожидаемый читается из того же `SCHEMA_SQL` — он применяется к временной базе в
памяти, и её `table_info` служит эталоном. Недостающие колонки добавляются через
`ALTER TABLE ... ADD COLUMN`.

Колонка, которую нельзя добавить к существующей таблице (`NOT NULL` без значения по умолчанию),
из сверки исключается: такое изменение требует настоящей миграции, и молчаливый отказ `ALTER`
был бы хуже расхождения.

Объекты схемы, которые никто не читает, удаляются там же (`DROP ... IF EXISTS`), чем чистятся и
базы, созданные прежними версиями.

## Последствия

- Второго списка, который нужно держать в согласии со схемой, не появляется: колонка мигрирует
  тем, что объявлена в DDL.
- Изменения, которые SQLite не умеет делать через `ALTER TABLE` (смена типа, переименование,
  `NOT NULL` без умолчания), этим механизмом не покрываются. Такое изменение потребует отдельного
  шага и, вероятно, нового ADR.
- `PRAGMA user_version` записывается как признак версии схемы, но решение о доработке принимается
  по фактическому составу колонок, а не по номеру.
- База, созданная любой прежней версией, открывается без отдельной команды обновления.
